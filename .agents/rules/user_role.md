# 👤 사용자 역할 및 개발 관점: 팀원 1 (OS 코어 엔지니어)

## 📌 기본 컨텍스트
- 사용자는 ContextPass 프로젝트의 **팀원 1 (클라이언트 시스템 엔지니어 / OS 코어)**입니다.

## 🛠️ 담당 영역 및 주요 태스크
1. **Windows Runtime API (`winsdk`)**:
   - `UserNotificationListener` 기반 백그라운드 토스트 알림 수신 리스너 구현
2. **활성 창 및 프로세스 추적 (`pygetwindow`, `psutil`, `SetWinEventHook`)**:
   - 사용자가 보고 있는 작업 화면 창 제목 및 프로세스명 실시간 추적/캐싱
3. **Windows 집중 지원 (방해 금지 모드) 연동**:
   - 알림 무음화를 위한 OS 집중 지원 상태 제어 및 가이드
4. **OS 로우레벨 최적화 및 시스템 통합**:
   - 백그라운드 상주 시 CPU 0.0% 이벤트 훅 최적화

## 🤖 에이전트 행동 지침
- 개발, 코드 작성, 디버깅 질문에 답변할 때 **팀원 1의 담당 영역(OS 코어, WinRT, 창 추적, 시스템 후킹)을 최우선 기준**으로 지원합니다.
- 다른 팀원의 모듈(AI 모델링, UI, 대시보드)과 연동할 때도 **'팀원 1의 산출물(이벤트/데이터 수집)을 어떻게 전달할 것인가'**의 관점에서 인터페이스를 설계합니다.
- 코드 작성, Git 작업 시 팀 공용 규칙을 반드시 확인: `docs/CONTRIBUTING.md`, `docs/codex-guidelines.md`
