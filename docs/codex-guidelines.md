# Codex 작업 지침

C# Windows 집중 모드 앱 Repository다. 사용자 로그인 세션에서 트레이에 상주하며 외부 AI 모듈과 연동한다.

## 필요한 문서만 읽기

사용자가 이 파일을 읽도록 요청한 경우 작업 기준으로 삼고, 작업 범위에 해당하는 문서만 추가로 읽는다.

- 프로젝트 소개·설치·실행·구조 변경: [README.md](../README.md)
- 브랜치·커밋·PR·CI: [CONTRIBUTING.md](CONTRIBUTING.md)

## 작업 원칙

- 관련 코드와 기존 변경을 확인하고 요청 범위만 수정한다. 다른 팀원의 작업을 덮어쓰지 않는다.
- 집중 시간은 경과 시간이다. 창을 닫아도 집중은 유지되며, 허용 알림은 캐릭터 말풍선 하나와 대기열로 처리한다.
- C# UI 요소는 UI 스레드에서만 변경한다. 백그라운드 결과는 선택한 UI 프레임워크의 Dispatcher를 통해 전달한다.
- 외부 AI의 내부 구현은 이 Repository에서 새로 만들거나 수정하지 않는다. 앱의 연동 코드와 개발용 Fake는 구현할 수 있다.
- Fake와 실제 AI는 같은 입출력 계약을 사용한다. Fake로 앱을 독립 개발하고, 합의된 공통 데이터 계약은 임의로 변경하지 않는다.
- `미정`과 `결정 필요`는 아직 합의되지 않은 사항이다. 공통 데이터·동작 정책을 임의로 확정하지 말고, 결정이 필요한 지점만 알린다. 독립 기능이나 Fake로 진행 가능한 작업은 계속한다.
- 상세 아키텍처, 새 의존성, 자동화를 작업과 무관하게 추가하지 않는다.
- 실제 코드와 문서가 다르면 구현 상태와 의도된 요구사항을 구분한다. 코드가 있다는 이유만으로 확정 요구사항을 바꾸지 않는다.
- 비밀값·실제 알림·활성 창 제목을 커밋하거나 개발 로그에 노출하지 않는다. 예제와 테스트는 가상 데이터를 사용한다.
- 변경에 맞는 기존 테스트와 실행 확인을 수행하고, 실행하지 못한 확인은 결과에 적는다. 문서만 수정했다면 내용과 링크를 확인한다.
- 결정이나 사용법이 바뀌면 해당 내용을 관리하는 문서 한 곳을 갱신한다. 중복 규칙과 새 문서를 불필요하게 늘리지 않는다.
